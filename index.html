Strix

The open-source AI pentesting tool. Autonomous AI hackers that find and fix your app’s vulnerabilities.

What is Strix?

Strix is a set of autonomous AI penetration testing agents that act like real hackers. They run your code dynamically, find vulnerabilities, and validate them with actual proofs-of-concept. It's built for developers and security teams who want fast, accurate security testing without the overhead of manual pentesting or the false positives of static analysis tools.

Key capabilities

  • Full pentesting toolkit: reconnaissance, exploitation, and validation out of the box
  • Multi-agent orchestration: teams of AI pentesters that collaborate and scale
  • Real exploit validation: working PoCs rather than scanner false positives
  • Developer-first CLI: actionable findings with remediation guidance
  • Auto-fix & reporting: generates patches and compliance-ready pentest reports

Features

Agentic pentesting tools

  • HTTP interception proxy (Caido)
  • Browser exploitation (XSS, CSRF, clickjacking, auth bypass)
  • Shell & command execution
  • Python exploit sandbox for PoCs
  • Recon & OSINT
  • SAST + DAST code analysis
  • Findings with CVSS scoring & OWASP classification

Vulnerability coverage

  • Broken access control
  • Injection (SQL, NoSQL, OS command, SSTI)
  • Server-side (SSRF, XXE, deserialization, RCE)
  • Client-side (XSS, prototype pollution, CSRF)
  • Business logic flaws
  • Authentication & session (JWT, session fixation)
  • Infrastructure & cloud misconfigurations
  • API security

Graph of agents

  • Specialized agents for recon, exploitation, and post-exploitation
  • Parallel execution across multiple targets
  • Agents share discoveries and chain vulnerabilities

Workflow

  • Headless mode (-n) for servers and CI
  • GitHub Actions / CI/CD integration
  • API testing from OpenAPI, Swagger, or Postman
  • Local web viewer: strix view
  • Connect your own MCP servers

Quick start

Prerequisites: Docker (running) and an API key from a supported LLM provider.

# Install Strix
curl -sSL https://strix.ai/install | bash

# Configure your AI provider
export STRIX_LLM="openrouter/z-ai/glm-5.3"
export LLM_API_KEY="your-api-key"

# Run your first security assessment
strix --target ./app-directory

The first run pulls the sandbox Docker image, and results are saved to strix_runs/<run-name>. This snippet comes from the project README. See the official quick start for current instructions.

Authorized use only. Only run Strix against systems you own or have explicit, written permission to test.
