# Strix showcase (unofficial)

This is a static page, `index.html` plus `style.css`, with no JavaScript. It presents [usestrix/strix](https://github.com/usestrix/strix) (Apache-2.0), and all content is summarized from the project README.

Serve it locally:

    cd /workspace/strix-site && python3 -m http.server 8000

Then open http://localhost:8000
